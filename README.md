# Open Source Lab

Java/Spring 백엔드 개발자를 목표로 실제 오픈소스를 읽고, 실행하고, 테스트하고, 작은 기여까지 이어가는 실습 기록입니다.

최신 기술은 흥미를 위한 실험으로 빠르게 다뤄보되, 실제 기여에서는 유지보수자의 범위와 테스트 증거를 우선합니다.

## 운영 방식

### 기여 트랙

- 낯선 저장소를 원본 상태로 실행합니다.
- 수정 전에 실패를 재현하거나 기대 동작을 적습니다.
- 한 가지 문제만 최소한으로 수정합니다.
- 테스트 결과와 판단 근거를 남깁니다.
- 외부 프로젝트의 코드는 해당 프로젝트를 fork한 저장소에서 다룹니다.

### 실험실 트랙

- Ollama, LangChain4j, Spring AI, MCP 같은 기술을 작은 기능으로 먼저 경험합니다.
- 실험 코드는 upstream 기여와 분리합니다.
- 동작 여부뿐 아니라 입력, 출력, 실패 조건을 기록합니다.

## 실습 경로

- [ ] GitHub 저장소, fork, clone의 관계 이해
- [ ] Spring Petclinic을 fork하고 로컬에서 원본 상태로 실행
- [ ] 관심 있는 HTTP 요청 하나의 Controller → Service 흐름 추적
- [ ] 백엔드 테스트 기초 학습 후 작은 수정과 회귀 테스트
- [ ] LangChain4j와 로컬 Ollama를 이용한 이슈 구조화 API
- [ ] 실제 오픈소스 이슈 재현과 PR 초안
- [ ] Spring AI 내부 코드 탐색
- [ ] MCP Java SDK 확장 실습

## 기록 규칙

각 실습은 다음 다섯 가지를 남깁니다.

1. 해결하려는 문제
2. 수정 전 예상
3. 직접 작성한 변경
4. 테스트 또는 실행 증거
5. 배운 점과 다음 질문

현재 시작점은 [00-baseline.md](learning-log/00-baseline.md)에 기록합니다.
