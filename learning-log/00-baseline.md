# 00. 시작 기준선

기준일: 2026-08-18

## 확인된 경험

- Java 21과 Spring Boot로 간단한 CRUD API를 작성했습니다.
- DTO 검증, 전역 예외 처리, HTTP 상태 코드를 실습했습니다.
- Ollama 비전 모델과 Pydantic 구조화 출력을 연결한 프로토타입을 실행했습니다.

## 앞으로 증명할 역량

- 낯선 오픈소스 저장소를 문서만 보고 실행하기
- 실패한 테스트에서 원인과 수정 경계를 찾기
- 수정 전후를 증명하는 회귀 테스트 작성하기
- 브랜치, 커밋, fork, Issue, Pull Request 흐름 익히기
- 리뷰 의견을 이해하고 최소 수정으로 반영하기

## 완료 판정

AI가 코드를 만들었거나 명령이 한 번 성공한 것만으로는 완료로 기록하지 않습니다.

다음 세 가지가 모두 있어야 완료입니다.

- 내가 직접 설명한 판단 근거
- 재현 가능한 테스트 또는 실행 결과
- 변경 범위를 확인할 수 있는 커밋

## 첫 체크포인트

- [x] GitHub 저장소, fork, clone의 관계를 내 말로 설명하기
- [x] Spring Petclinic을 내 GitHub 계정으로 fork하기
- [x] fork한 저장소를 로컬에 clone하기
- [x] `origin`과 `upstream`의 관계 확인하기

확인 메모(2026-08-21): `fork`는 다른 사람의 GitHub 저장소를 내 GitHub 계정으로 복사하는 것이고, `clone`은 GitHub 저장소를 Mac의 로컬 폴더로 복사하는 것이다.
